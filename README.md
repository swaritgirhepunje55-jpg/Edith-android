# EDITH Android - Created by Swarit Girhepunje

## Build APK (Free, No Linux needed)

1. Create GitHub account at github.com
2. Create new private repo called "edith-android"
3. Upload ALL files from this folder to the repo
4. Go to Actions tab → "Build EDITH APK" → "Run workflow"
5. Wait 20-40 minutes
6. Download APK from Artifacts section

## Install on Phone
- Send APK to phone via WhatsApp/Drive
- Enable "Install unknown apps" in settings
- Install and run EDITH

## First Launch
- Allow microphone permission
- Wait 30 seconds for server to start
- Add Groq API key in Settings
